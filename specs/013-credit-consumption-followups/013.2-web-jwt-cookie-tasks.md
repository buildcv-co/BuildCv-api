## Risks

1. **Art. VI amendment rejection** — If owner rejects NextAuth dep, must revert to Option A (cookie-based). Mitigation: Option A design is preserved in design history.
2. **Shared secret distribution** — `NEXTAUTH_SECRET` MUST match `JwtSettings:Secret` byte-for-byte. Mitigation: fail-fast startup check + integration test asserting validation.
3. **NextAuth v4 lock-in** — Tight coupling to NextAuth's callback pattern. Mitigation: documented in design as future-migration cost.
